# Анализ проекта Pipka

**Pipka — AI Job Search Platform (Агент поиска работы)**

Это агрегатор вакансий с AI-скорингом для поиска работы уровня Director/VP/Head (а также Manager и Senior) на рынке DACH+ (Германия, Австрия, Швейцария и др.). Система автоматизирует поиск релевантных вакансий и экономит время на отсев неподходящих предложений.

## 1. Архитектура и Стек Технологий
*   **Backend:** Разработан на Python 3.12 с использованием FastAPI.
*   **База данных:** PostgreSQL 16 с использованием asyncpg и SQLAlchemy 2.0 (async). Активно используются JSONB и pgvector (для семантического поиска). Миграции управляются Alembic.
*   **AI/LLM Интеграции:**
    *   **Google Gemini Flash:** Используется как основной бесплатный backend для backfill скоринга и разового анализа вакансий, а также для получения embeddings.
    *   **Anthropic Claude (Sonnet):** Выступает в роли fallback-решения, если не задан Gemini API ключ, а также для скоринга в реальном времени.
    *   **NVIDIA Build (Gemma-4-31b-it):** Используется как "idle rescorer" (перепроверка старых вакансий в фоновом режиме).
*   **Планировщик задач:** APScheduler для регулярного сканирования (каждые 3 часа), фонового скоринга (каждые 2 часа) и других задач.
*   **Интерфейсы:**
    *   **Telegram-бот:** Для push-уведомлений о подходящих вакансиях (используется python-telegram-bot).
    *   **Web Dashboard:** SPA на чистом HTML/JS/CSS с аутентификацией через Google OAuth2.
*   **Деплой:** Docker Compose (FastAPI + Bot + Scheduler в одном контейнере, DB в другом) на VPS-сервере (Contabo).

## 2. Ключевые фичи и бизнес-логика
*   **Агрегация из множества источников:** Система собирает вакансии с 9 разных площадок (Adzuna, JobSpy, Arbeitnow, Arbeitsagentur, Xing, BerlinStartupJobs, WTTJ, Jooble, Remotive) плюс имеет целевой watchlist компаний.
*   **Продвинутая дедупликация:** Работает на уровне точного хэша (SHA-256) и нечеткого поиска (fuzzy match по названию и компании).
*   **Двухэтапный скоринг вакансий:**
    1.  **Rule-based pre-filter (Быстрый):** Отсеивает неподходящие вакансии (джуниоры, не те функции, требования других языков, зарплата) и распределяет их по приоритетам (high, medium, manager_tier2, low).
    2.  **AI Скоринг (Дорогой):** Выполняется через LLM для глубокого анализа соответствия резюме.
*   **Семантический поиск (pgvector):** Внедрены векторы (embeddings) для вакансий и профилей. Это позволяет ранжировать вакансии по близости к профилю пользователя до запуска AI-скоринга.
*   **Проверка актуальности ссылок (URL liveness):** Ежедневный HEAD-ping для скрытия закрытых вакансий.
*   **Трекер откликов:** Позволяет сохранять статус по вакансиям (applied, rejected, interviewing и т.д.) и реализовано авто-исключение компаний (после 5 отказов).

## 3. Оценка проекта
Проект написан очень качественно и профессионально.
*   **Отличная документация:** Проект содержит встроенную Wiki на базе Obsidian (`docs/pipka-wiki/`).
*   **Продуманная безопасность:** Реализованы защиты от CSRF, Rate Limiting (пользовательский и по IP), ограничение размера загружаемого файла (резюме), фильтрация PII-данных для Sentry и валидация инпутов.
*   **Оптимизация затрат на API:** Двухэтапный скоринг, кэширование скоров на 7 дней, fallback-цепочки моделей и semantic skip — всё это эффективно экономит лимиты API.
